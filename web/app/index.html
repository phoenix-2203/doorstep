Let people pay into your Arc app from any wallet or exchange.

On Arc, pressing "Send USDC" in a wallet can't pay into most apps: savings vaults, escrows and checkouts only accept money through their own deposit button. Doorstep gives each payer an address. Whatever arrives there is put into the app for them automatically, or sent back if that isn't possible.

  1. Send to an addressFrom any wallet, or straight from an exchange like Coinbase or Binance. No app to connect, no buttons to find.
  2. Delivered automaticallyDoorstep puts the money into the app within seconds, credited to the right person. The small network fee (under $0.01) comes out of the payment.
  3. Or sent backIf it can't be delivered, it goes back. Nobody can redirect it: the address is calculated from its instructions.

Try it: a savings vault you can top up from anywhere

This demo app is a simple savings vault on Arc mainnet. Your wallet can't send to it directly. Doorstep gives you your own address that can. Uses real USDC; try a small amount.

Accept payments into your contract from any wallet or exchange.

Give each payer a Doorstep address. When USDC lands, Doorstep calls your contract's deposit function with the amount and the person to credit. If the call fails or the time limit passes, the money goes back to the refund address. No backend needed: the address is calculated from the instructions, and anyone can deliver.

Install the SDK

npm install doorstep-arc viem
import { createDoorstep } from 'doorstep-arc';

const ds = createDoorstep();               // Arc mainnet

const intent = ds.depositIntent({
  into: '0xYourVault',                     // has deposit(uint256 amount, address to)
  beneficiary: customer,                   // who gets credited
  refundTo: customer,                      // where it goes if it can't be delivered
  minimum: '1',                            // USDC
  expires: '30d',
  reference: 'order-1042',
});

ds.depositAddress(intent);                 // show this, or a QR code
ds.describe(intent);                       // one paragraph your payer can read
ds.watch(intent, (e) => console.log(e.type)); // waiting, landed, bounced

Your contract must take the deposit with transferFrom (Doorstep approves exactly the amount, then revokes). Any ERC-4626 vault works as-is. Full API: SDK readme.

Or use the hosted API

No SDK needed: one HTTPS call returns an address and a ready pay page, and a signed webhook tells your server when the money lands. API reference · API keys on request (GitHub issue).

curl -X POST https://api.104-251-218-80.sslip.io/v1/addresses \
  -H "Authorization: Bearer $DOORSTEP_KEY" -H "content-type: application/json" \
  -d '{"into":"0xYourVault","beneficiary":"0xCustomer","refundTo":"0xCustomer",
       "amount":"25","reference":"inv-1042","webhookUrl":"https://yourapp.com/hooks/doorstep"}'

→ { "address": "0x…", "payLink": "https://…", "registered": true, "invoice": { "state": "unpaid", … } }

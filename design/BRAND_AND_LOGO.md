# Brand and logo

## Idea: the payment threshold

An open arch is the receiving contract; a lime arrow is a payment crossing into it; a dot marks arrival. The arch is open at the bottom because an address is a way in, not a container.

## Files (`web/brand/`)

| File | Use |
| --- | --- |
| `icon.svg` | App icon: forest tile, white arch, lime arrow and dot. Favicon. |
| `mark.svg` | Mark without the tile, uses `currentColor` for the arch so it works on light and dark. |
| `logo.svg` | Horizontal lockup: mark + lowercase `doorstep`. |
| `logo-mono-dark.svg`, `logo-mono-light.svg` | One-colour versions for dark and light surfaces. |
| `apple-touch-icon.png` | 180 px touch icon rendered from `icon.svg`. |

## Rules

- Lime (`#B9F27C`) appears only on forest or dark surfaces, never as text on light backgrounds (contrast).
- Keep clear space of one dot-width around the mark. Minimum size 16 px (favicon).
- Wordmark is always lowercase, set in Schibsted Grotesk Bold, tracking −2%.
- No gradients, shadows or animation on the logo itself.
